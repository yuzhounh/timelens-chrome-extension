Chrome 扩展 · 网站访问计时

给浏览时间，一个清晰的刻度。

自动统计有效浏览时间，以网站排行和趋势回顾你的浏览习惯。

前往 Chrome 应用商店GitHub 发布版

当前 GitHub 公开发布版：v1.6.10。安装后的程序或扩展负责采集与展示记录。

用简单的方式，了解使用习惯

有效浏览计时

统计当前激活网页的浏览时间，切换窗口或电脑空闲时自动暂停。

直观查看趋势

从工具栏查看今日排行，在仪表盘中回顾网站用时与日期趋势。

保留自己的记录

支持 JSON 备份、导入与数据管理，可按需要排除指定网站。

开始使用

  1. 在 Chrome 应用商店安装，或从 GitHub Releases 下载扩展。
  2. 固定工具栏图标，正常浏览网站即可开始计时。
  3. 点击扩展查看今日统计，打开完整仪表盘回顾浏览趋势。
