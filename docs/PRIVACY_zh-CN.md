# 时光镜 (Time Lens) 隐私政策

**最后更新：** 2026 年 10 月 19 日（本地 Firebase 同步版）

**联系方式：** [GitHub Issues](https://github.com/yuzhounh/timelens-chrome-extension/issues)

---

## 概述

时光镜是一款通过 Google 账户同步多台设备的网站计时扩展。登录 Google 后，统计记录和通用设置自动同步至 `timelens-chrome-extension` 项目的 Firebase Authentication 与 Cloud Firestore，按账户与设备分别保存。本机记录与缓存用于支持离线计时和联网补传；云端同步需要先完成 Google 登录。

---

## 扩展收集哪些数据

浏览网页时，扩展会按**网站域名**记录：

新记录还按设备本地小时累计浏览时长，用于分析小时规律；小时明细参与同步并包含在 JSON 备份中。旧的每日记录不会被推算为小时数据。

| 数据 | 用途 |
|------|------|
| 域名 (hostname) | 按网站汇总统计 |
| 有效浏览时长 | 统计在各网站花费的时间 |
| 访问次数 | 统计打开网站的次数 |
| 页面标题和 URL | 在仪表盘中显示「最近访问」 |

您可以自定义设备名。扩展为每个浏览器配置随机生成一个标识，不读取硬件标识。启用同步后，设备名和标识会随设备记录与报告上传。改名和扩展升级不会改变标识；卸载或清除扩展存储后会重新生成。

### 默认**不会**收集

- 密码、表单输入或页面正文内容
- Chrome 内部页 (`chrome://`)、扩展页或本地文件
- 您在设置中排除的域名

### 「有效浏览」的定义

仅在以下条件下计时：

- 标签页位于**当前活动窗口**
- 标签页**处于焦点**
- 电脑**非空闲**（根据您设置的空闲阈值）

## 数据存储位置

| 存储 | 内容 |
|------|------|
| 本机 `chrome.storage.local` | 每日访问统计、已生成报告、扩展设置 |
| `chrome.storage.session` | 当前跟踪会话的临时状态（浏览器会话结束后清除） |

您可在「数据管理」中导出 JSON 备份，或使用「清除数据」删除全部记录。

---

## 权限说明

| 权限 | 用途 |
|------|------|
| `storage` / `unlimitedStorage` | 本地保存统计与设置 |
| `tabs` | 读取活动标签页的 URL 和标题 |
| `idle` | 检测电脑空闲并暂停计时 |
| `alarms` | 调度周期报告自动生成 |
| `offscreen` | 通过 Firebase 登录辅助页完成 Google 登录 |
| `<all_urls>` | 访问您浏览的 http/https 页面 URL |

## 已停用的报告和邮件功能

当前本地版不再生成周期报告或发送邮件。已有报告和设置为兼容备份继续保留；旧报告闹钟及邮件任务不再执行。

## 第三方服务

扩展本身不包含分析或广告 SDK。

Google 账户同步使用 Firebase Authentication 和 Cloud Firestore，适用 Google 对应服务的隐私政策。

---

## 数据共享

我们**不会**出售或出租您的浏览数据。数据是否传出设备取决于您启用的功能。

- 手动导出时，数据会写入由您选择下载的 JSON 文件。
- Google 登录后，域名、时长、访问次数、页面标题与 URL、报告、设备名称和通用设置自动同步至香港区域（`asia-east2`）Cloud Firestore。Google Authentication 处理账户身份。数据库规则将访问限制为当前登录账户自己的记录。

同步通过 Firebase 实现，未使用 Chrome 的 `chrome.storage.sync`。认证令牌保存在仅扩展可信上下文可访问的本地存储；邮件网关令牌和待发送任务不上云。退出账户会停止同步，保留本地记录和已下载缓存。

---

## 数据保留与删除

- 数据保存在本机，直至您删除或卸载扩展
- 使用仪表盘「清除数据」删除本机产生的统计与报告；保持登录并成功同步后，该变化同步到云端，不删除其他设备产生的记录。
- 卸载扩展后，相关本地数据将随 Chrome 机制清除
- 单独卸载不会删除云端记录。如需删除本机当前云端记录，应先清除本机数据并完成同步；项目所有者也可在 Firebase 控制台管理云端记录。

---

## 儿童隐私

本扩展不面向 13 岁以下儿童，也不会故意收集儿童个人信息。

## 政策变更

扩展功能更新时我们可能修订本政策。顶部「最后更新」日期将同步更新。
