# 时光镜 (Time Lens) 隐私政策

**最后更新：** 2026 年 8 月 30 日

**联系方式：** [GitHub Issues](https://github.com/yuzhounh/timelens-chrome-extension/issues)

---

## 概述

时光镜是一款**本地优先**的 Chrome 扩展。默认情况下，您的浏览统计数据**仅保存在本机**，开发者不会运营中央服务器收集您的浏览历史。

---

## 扩展收集哪些数据

浏览网页时，扩展会按**网站域名**记录：

| 数据 | 用途 |
|------|------|
| 域名 (hostname) | 按网站汇总统计 |
| 有效浏览时长 | 统计在各网站花费的时间 |
| 访问次数 | 统计打开网站的次数 |
| 页面标题和 URL | 在仪表盘中显示「最近访问」 |

### 默认**不会**收集

- 密码、表单输入或页面正文内容
- Chrome 内部页 (`chrome://`)、扩展页或本地文件
- 您在设置中排除的域名

### 「有效浏览」的定义

仅在以下条件下计时：

- 标签页位于**当前活动窗口**
- 标签页**处于焦点**
- 电脑**非空闲**（根据您设置的空闲阈值）

---

## 数据存储位置

| 存储 | 内容 |
|------|------|
| 本机 `chrome.storage.local` | 每日访问统计、已生成报告、扩展设置 |
| `chrome.storage.session` | 当前跟踪会话的临时状态（浏览器会话结束后清除） |

您可在「数据管理」中导出 JSON 备份，或使用「清除数据」删除全部记录。

---

## 权限说明

| 权限 | 用途 |
|------|------|
| `storage` / `unlimitedStorage` | 本地保存统计与设置 |
| `tabs` | 读取活动标签页的 URL 和标题 |
| `idle` | 检测电脑空闲并暂停计时 |
| `alarms` | 调度周期报告自动生成 |
| `<all_urls>` | 访问您浏览的 http/https 页面 URL |

---

## 可选邮件备份（用户自行配置）

若在设置中启用**邮件备份**，扩展会将周期报告发送至**您配置的邮件网关 URL**（例如仓库中提供的 Cloudflare Worker 示例）。

启用后，以下数据**仅会发送给您配置的网关**：

- 报告摘要（周期、总计、网站排行）
- 包含报告数据的 JSON 附件
- 您配置的收件邮箱和网关访问令牌，用于授权并投递邮件

扩展**不会**内置邮件 API 密钥；网关、收件邮箱和访问令牌均由您自行控制。

---

## 第三方服务

扩展本身不包含分析或广告 SDK。

若您配置了邮件网关（如通过 Resend），则适用该服务的隐私政策。

---

## 数据共享

我们**不会**出售、出租或共享您的浏览数据。本扩展不会自动把浏览统计传出您的设备。

- 手动导出时，数据会写入由您选择下载的 JSON 文件。
- 只有在您启用邮件备份并配置自有网关后，浏览统计才会传出设备。

本扩展使用 `chrome.storage.local` 而非 `chrome.storage.sync`，不会通过您的 Google 账号自动同步浏览统计。

---

## 数据保留与删除

- 数据保存在本机，直至您删除或卸载扩展
- 使用仪表盘「清除数据」可删除全部统计与报告
- 卸载扩展后，相关本地数据将随 Chrome 机制清除

---

## 儿童隐私

本扩展不面向 13 岁以下儿童，也不会故意收集儿童个人信息。

---

## 政策变更

扩展功能更新时我们可能修订本政策。顶部「最后更新」日期将同步更新。

---

## 您的权利

由于数据保存在本机，您可随时通过扩展界面访问、导出或删除全部数据。

如有疑问，请在 GitHub 提 Issue，或通过 Chrome 网上应用店联系开发者。
